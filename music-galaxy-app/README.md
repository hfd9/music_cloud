# 音乐星际 · 交互验证原型

当前交付是一个无需安装依赖的交互验证版，位于 `prototype/`。它使用 Canvas 的三维坐标投影，不是正式 React / TypeScript / Three.js 引擎，也不表示开发文档中的 T02 或完整 P0 已完成。当前执行环境无法访问 npm；先验证探索体验，后续按文档迁移引擎和界面。

## 本地运行

```sh
cd music-galaxy-app
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。无 npm 安装步骤，没有 CDN、外部图片或远程曲库请求。

也可直接双击项目里的 `preview.html` 打开，完全无需服务器。源码修改后用 `npm run build:preview` 更新这个单文件预览。当前执行环境禁止监听本地端口，因此使用此方式交付预览。

## 探索方式

- 拖动：平移漫游；滚轮：朝指针位置缩放；Shift + 拖动或右键拖动：旋转。
- 触摸：单指移动、双指缩放和平移。
- 靠近一位歌手会自动展开 5 首歌曲，远离会收起。不必搜索或点击“进入星系”。
- 单击歌手查看详情，单击歌曲查看播放入口。点击播放后仍可以继续探索。
- 查看别的歌曲详情不会中断当前播放；点击其播放按钮才会切歌。
- 详情中的“靠近这位歌手”、风格入口和搜索列表都是可选快捷方式。
- Canvas 聚焦后可用方向键移动、加减号缩放、Home 返回。完整歌手/歌曲列表也可用键盘操作。
- 设置可切换三档画面细节及减少动态效果，默认尊重系统动效偏好。

## 数据和声音

200 位歌手与 1,000 首歌曲均为虚构演示实体，地区属性也是虚构测试字段，不可当成真实元数据。固定随机种子和 ID 保证每次启动位置一致。人数、亮度与大小是标注的模拟指标；未知与真实零值分别显示。

音频为本地 Web Audio 振荡器生成的 45 秒合成片段，不是歌手真实作品。只用于验证播放/暂停、切歌、音量和局部律动。没有实时人数后台，不会上报播放心跳或把演示播放计为真实热度。

## 视觉更新

风格星云使用由真实演示节点位置生成的不规则三维云团，没有固定螺旋或旋臂模板。区域歌手数量控制整体浓度和亮度，固定尺度的局部密度控制云团内部的亮暗，歌手聚集处更浓、更亮；不逐区域归一化成同样亮度。区域数量分别为 12、42、18、31、15、9、24、49，总计仍为 200。种子固定，刷新与画质切换不会改变云团轮廓；星尘是装饰，不计入区域数量。

歌手星点使用风格颜色、亮芯和少量星芒。靠近后保留歌手核心星尘、歌曲轨道和带阴影/条纹/部分星环的歌曲星球。光晕与云气纹理缓存复用，减少逐帧生成。没有生成图片或引入外部视觉资产。

此前已在本机 Edge 验证风格靠近、缩放自动展开歌曲、直接点星球打开详情。历史近景短时读数约 60 FPS、P95 帧间隔 18 ms 属于上一版视觉，不作为新云团性能结果。目录、导航、播放和云团数量/局部密度/稳定性均有检查；手机触摸、完整可访问性和长时性能尚待验证。
